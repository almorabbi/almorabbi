# فوازير نور العائلية وفوازير قناديل رمضان (B41 / D9)

- **المساحة الدائمة (16 فزورة طوال العام):** أربع مهارات ذهنية ثنائية اللغة (العربية والإنجليزية) بأسلوب «الورق المقصوص» (Paper-Cut) الخالي تمامًا من الإعلانات والعملات أو الألفاظ المحبطة:
  1. دقة الملاحظة والفروق (`spot_diff`)
  2. التفكير الجانبي والمفاجأة (`trick_reveal`)
  3. التركيب الهندسي (`piece_assembly`)
  4. التسلسل المنطقي ومسار الماء (`water_path`)
- **الحزمة الموسمية (30 فزورة لليالي رمضان):** تغطّي الليالي 1–30 في `mobile/assets/content/games/ramadan_puzzles.{ar,en}.json` مع تعليق صوتي هادئ اختياري وإضاءة تلقائية لقنديل الليلة في `POST /api/programs/ramadan/fawazir`.
- **الالتزام الشرعي والتربوي:** بلا تصوير للأشخاص أو الأرواح، وب«همسة للمربّي» السقراطية التي تفتح حوارًا بين الوالد وطفله ثم فكرة ذكاء بلا شاشة بعد كل جولة.
