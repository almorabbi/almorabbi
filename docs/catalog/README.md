# كتالوج المشروع — المربّي الذكي (almorabbi)

> **هذا هو المدخل الإجباري لأي وكيل/مطوّر يفتح المشروع.** اقرأ القسم المناسب **قبل** أي تعديل، وحدّثه **في نفس الـcommit** بعد التعديل. سؤال عن المشروع؟ الجواب هنا أولًا.

## ما هو المشروع

مساعد تربوي إسلامي آمن للأهل: **باكند FastAPI + RAG** (ChromaDB + BM25 + Cross-Encoder) فوق **قاعدة معرفة JSON** (1060 وحدة عربية + 360 إنجليزية)، يُجيب بحواجز سلامة (طوارئ/فتوى/عقاب بدني/إحالة طبية)، مع **منهج** (43 مسارًا · 205 دروس · 220 نصيحة) و**سطح للأطفال** (وضع الطفل، مهام، اتفاقية، رخصة إنترنت) و**برامج أسرة** (رمضان، رحلة الصلاة، المراحل) و**مكتبة قصص** (47 قصة: حكايات + «قصص الأنبياء من القرآن» + «من السيرة النبوية») وشخصية «نور». يصل المستخدم عبر **تطبيق Flutter (Android، حزمة `com.alsaba.almorabbi`)**؛ مجاني بلا إعلانات.
حول المشروع خطوط محتوى وتشغيل (مولّدات NotebookLM/ترجمة/ريلز، تقارير تلجرام، نشر Play، E2E).

## قواعد الوكلاء (اتفاقية)

1. **اقرأ قبل التعديل:** الملف المعني من هذا الكتالوج، و`08-gotchas.md` دائمًا قبل أي شغل (§0 خاص بهذا الريبو).
2. **حدّث في نفس الـcommit:** أضفت/حذفت/غيّرت ملفًا أو مسارًا أو جدولًا أو متغير بيئة أو ميزة ⇒ عدّل الصف المقابل هنا (FEATURES / 02 / 03 / 04 / 07).
3. **أسماء متغيرات البيئة فقط** — ممنوع قيم أو مفاتيح أو توكنات في الكتالوج (ولا في أي ملف أو commit أو سطر أمر).
4. **الريبو عام:** ممنوع أي اسم شخصي أو مسار منزلي أو حساب شخصي أو عنوان IP في الكتالوج والكود والكوميتات؛ هوية الكوميت المحلية ثابتة. للمشغّل خطوة تنضيف قبل كل commit.
5. **الشغل في شجرة معزولة** (`git worktree add -b <فرع> /tmp/wt-<اسم> origin/main`) ← PR ← دمج بقرار. لا تبديل فرع في الشجرة الرئيسية. تغيير تشغيلي ⇒ قيد مؤرَّخ في سجل العمليات لدى المشغّل.
6. **التحقق بالأثر:** healthy ≠ exit 0 (نشر؟ حاوية healthy + `/health` + سؤال حقيقي يُجاب؛ إشعار؟ وصل لجهاز؛ كرون؟ صف/ملف/رسالة).
7. **الجواب يخرج من الكتالوج:** إن لم يوجد، اسأل المسؤول مرة واحدة وسجّل الجواب هنا.
